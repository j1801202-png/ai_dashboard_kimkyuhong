Firebase 설정 필요

이 대시보드를 사용하려면 Firebase 프로젝트 설정이 필요합니다.
아래 단계를 따라 설정 후 HTML 파일을 수정하세요. 

1. https://console.firebase.google.com 접속
2. 새 프로젝트 생성 (Google Analytics 선택사항)
3. Authentication → 시작하기 → Google 로그인 방법 활성화
4. Firestore Database → 데이터베이스 만들기 (테스트 모드)
5. 프로젝트 설정(⚙️) → 내 앱 → 웹앱(</>) 추가
6. firebaseConfig 코드 복사 → HTML 상단 firebaseConfig 교체

EmailJS (선택):
1. https://www.emailjs.com 회원가입
2. Email Services → Gmail 추가
3. Email Templates → 템플릿 생성
4. Account → Public Key 복사 → HTML EMAILJS_* 상수 교체
